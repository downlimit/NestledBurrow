# NestledBurrow: активная работа

## Назначение

`ROADMAP.md` хранит только активную задачу, ближайший продуктовый вопрос и следующий свободный номер. История и состояние PR принадлежат GitHub, а системное состояние — `systems/*.md`.

## Task identity

```text
Task #001 — Первая расчистка участка
```

Номера не переиспользуются. Ветка: `task/<number>-<slug>`.

**Следующий свободный номер:** `Task #098`.

## Сейчас

### Task #097 — Формат обслуживания из меню и инфраструктуры

**Результат:** конкретный визит получает способ обслуживания из реального предложения и доступной инфраструктуры, без отдельного переключателя типа заведения: горячее блюдо остаётся обслуживанием на месте, переносимый напиток может уйти навынос, а заранее выставленный подходящий товар позволяет самообслуживание без ручного принятия заказа. У каждого посетителя сохраняются собственные заказ, оплата, история и обратная связь; отсутствие обязательной для выбранного способа обслуживания мощности остаётся реальным отказом открытого заведения.

## Следующий продуктовый вопрос

После игровой проверки Stage 8 определить первую границу Stage 9: какие изменения отношений и жизненного цикла нужны раньше всего, чтобы семьи, возраст, смерть и пополнение населения углубляли узнаваемых жителей без запуска полной фоновой симуляции каждого человека.

## Правило актуализации

- Лид добавляет новую активную задачу один раз до handoff или direct implementation и сразу увеличивает следующий номер.
- Текущая запись не редактируется ради PR-номера, `принято`, Ready или merge: эти состояния принадлежат GitHub.
- При начале следующей задачи она заменяет предыдущую в секции `Сейчас`.
- Здесь не хранятся merge SHA, длинные ретроспективы, список прошлых задач или подробности механик.
