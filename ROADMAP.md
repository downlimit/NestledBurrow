# NestledBurrow: активная работа

## Назначение

`ROADMAP.md` хранит только активную задачу, ближайший продуктовый вопрос и следующий свободный номер. История завершённых PR принадлежит GitHub, а системное состояние — `systems/*.md`.

## Task identity

```text
Task #001 — Первая расчистка участка
Task #001 — Первая расчистка участка (PR #81)
```

Номера не переиспользуются. Ветка: `task/<number>-<slug>`.

**Следующий свободный номер:** `Task #057`.

## Сейчас

### Task #056 — Гниение только в полностью сухой почве

**Статус:** `Завершено`.

**Результат:** гниение больше не привязано к моменту последнего полива. Счётчик растёт только при 0% влажности почвы и полностью сбрасывается от лейки или дождя. Ни разу не политое семя гниёт через 24 полностью сухих часа, а уже получавшее воду растение — через 48.

## Следующий продуктовый вопрос

Какие первые четыре боевые способности должны занять крест `SPACE / LMB / RMB / SHIFT`?

До подтверждения пользователя это не зарегистрированная задача.

## Правило актуализации

- Лид добавляет сюда новую задачу до handoff и сразу увеличивает следующий номер.
- Исполнитель в принятом PR оставляет только актуальный статус и краткий результат.
- После завершения следующей задачи предыдущая удаляется из секции `Сейчас`.
- Здесь не хранятся merge SHA, длинные ретроспективы, список всех прошлых задач или подробности механик.
